## Real prepublication failure

Publish [39226036184](https://github.com/Zigerry/cliproxy-usage/actions/runs/39226036184) passed both actual tagged SDK test/type jobs. The publishing job passed source/provenance-context gating, original-lock installation and real tar inspection, then stopped at **Verify npm state and reject downgrades** with `Expected JSON object`.

An unauthenticated official-registry request established the response:

```text
GET https://registry.npmjs.org/cliproxy-usage/0.6.0
HTTP 404
Content-Type: application/json
JSON value type: string
"version not found: 0.6.0"
```

The reader incorrectly required a JSON object before examining HTTP404. The simulation had modeled object-shaped404 errors, so it did not exercise the real server's version-missing string. This is a release-tool parsing bug, **not evidence of an npm authentication failure**.

No npm publish step ran. No GitHub draft/assets or public release was created. At this stop, npm latest and GitHub latest public Release both remain **0.5.1**. Local npm is not logged in; the Actions token's validity, package permissions and actual npm provenance remain untested.
